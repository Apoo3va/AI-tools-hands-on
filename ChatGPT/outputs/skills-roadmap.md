# Ideal Skill Stack Before Graduation

If you're an ECE student targeting AI/ML roles, try to graduate with:

* Python, SQL, Git, Linux
* NumPy, Pandas, Scikit-Learn
* Machine Learning & Statistics
* PyTorch and/or TensorFlow
* Computer Vision
* NLP
* Generative AI (RAG, LLMs)
* Docker & Basic Cloud (AWS/GCP)
* FastAPI Deployment
* 10–15 Projects
* 1–2 Internships
* 300–500 DSA Problems Solved

This combination is sufficient to be competitive for AI/ML Engineer, Computer Vision Engineer, Data Scientist, and AI Research Intern roles.
