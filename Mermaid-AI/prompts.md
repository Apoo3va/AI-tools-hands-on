# Prompts Used

## Prompt 1 – Flowchart

Create a Mermaid flowchart for a Smart College Management System showing student registration, course enrollment, attendance management, examination process, result generation, and report access.

---

## Prompt 2 – User Journey

Create a Mermaid user journey diagram representing a student's interaction with a Smart College Management System from login to accessing academic reports.

---

## Prompt 3 – Class Diagram

Create a Mermaid class diagram for a Smart College Management System including Student, Faculty, Course, Attendance, Examination, Result, and Admin classes with relationships.

---

## Prompt 4 – Sequence Diagram

Create a Mermaid sequence diagram showing how a student enrolls in a course through the Smart College Management System including interactions with the portal, database, and admin.
