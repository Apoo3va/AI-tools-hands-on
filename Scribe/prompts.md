# 🤖 Scribe Prompt – LinkedIn Profile Creation Guide

This file contains the structured prompt used to generate a step-by-step documentation guide.

---

## 📌 Master Prompt Used

> Create a detailed step-by-step process guide for beginners on:  
> "How to Create a LinkedIn Profile"
>
> The guide should include:
>
> ### 1. Step-by-step Instructions
> - Break the entire process into simple numbered steps  
> - Use beginner-friendly language  
>
> ### 2. Screenshot Guidance
> - Indicate where screenshots should be taken  
> - Describe what each screenshot should show  
>
> ### 3. Clear Formatting
> - Use headings and bullet points  
> - Keep instructions simple and easy to follow  
>
> ### 4. Final Output
> - A structured guide suitable for sharing as a documentation page or Scribe document
