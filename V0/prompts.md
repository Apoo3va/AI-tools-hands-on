# 🤖 V0 Prompts – Student Learning Portal UI Design

This file contains all prompts used to generate the UI screens for the Student Learning Portal.

---

## 📌 1. Login Page Prompt
> Design a modern and minimal login page for a Student Learning Portal.  
> Include email input, password input, login button, and a clean academic UI style.  
> The design should feel professional, simple, and student-friendly.

---

## 📌 2. Dashboard Prompt
> Create a student dashboard for a learning portal.  
> It should show:
> - Welcome message  
> - Course overview cards  
> - Recent activity section  
> - Progress summary  
>  
> Make it clean, modern, and easy to navigate.

---

## 📌 3. Courses Page Prompt
> Design a courses page for a student learning platform.  
> Include:
> - List of enrolled courses  
> - Course cards with progress bars  
> - Course titles and instructor names  
> - Enroll/open course buttons  

---

## 📌 4. Progress Tracking Page Prompt
> Create a progress tracking page for students.  
> Include:
> - Visual progress bars  
> - Completion percentage  
> - Subject-wise progress breakdown  
> - Simple and clean analytics UI  

---

## 📌 5. Profile Page Prompt
> Design a student profile page.  
> Include:
> - Profile picture  
> - Student details  
> - Enrolled courses summary  
> - Progress stats  
> - Edit profile button
