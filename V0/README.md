# 🎨 V0 – UI/UX Design Sprint (Student Learning Portal)

## 🎯 Objective
This project focuses on designing a clean and functional **Student Learning Portal** using AI-assisted UI generation tools. The goal was to create a user-friendly academic platform with a modern interface and intuitive navigation.

---

## 🛠 Tool Used
- V0 (AI UI Generator)

---

## 📌 Project Scope
The Student Learning Portal includes the following core pages:

- 🔐 Login Page  
- 📊 Dashboard  
- 📚 Courses Page  
- 📈 Progress Tracking Page  
- 👤 Profile Page  

---

## 🧩 Design Approach
The design was created with a focus on:
- Simplicity and clarity  
- Student-friendly UI  
- Easy navigation flow  
- Clean modern layout
