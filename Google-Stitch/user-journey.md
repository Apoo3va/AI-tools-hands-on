# 🚶 User Journey – Career Guidance App

## 👤 User Persona
A college student unsure about career direction.

---

## 🔄 Step-by-Step Journey

### 1️⃣ Entry Point
User opens the app and lands on the login page.

---

### 2️⃣ Dashboard
After login, user sees:
- Welcome message  
- Quick access to features  
- Start Career Test button  

---

### 3️⃣ Skill Assessment
User takes a short quiz:
- Aptitude questions  
- Interest-based questions  
- Skill level evaluation  

---

### 4️⃣ AI Recommendation
App generates:
- Suggested career paths  
- Skill match percentage  
- Explanation of recommendation  

---

### 5️⃣ Career Detail Page
User views:
- Career roadmap  
- Required skills  
- Learning resources  

---

### 6️⃣ Profile Page
User can:
- Save careers  
- Track progress  
- Update profile  

---

## 🎯 Final Experience
The journey is designed to be simple, guided, and decision-focused, helping students reduce confusion and take action.
