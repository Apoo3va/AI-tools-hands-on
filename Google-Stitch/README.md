# 📱 Google Stitch – App Design from Prompt

## 🎯 Objective
This project focuses on designing a complete mobile application using AI-powered design generation tools. The goal was to convert a simple idea into structured wireframes, UI screens, and a functional user flow.

---

## 🛠 Tool Used
- Google Stitch (AI App Design Tool)

---

## 📌 Selected App Idea
**Career Guidance App**

---

## 🧩 App Purpose
The Career Guidance App helps students:
- Explore career options
- Get personalized career recommendations
- Track skill development
- Access learning resources
- Connect with mentors

---

## 📦 Deliverables

### 📐 Wireframes
Low-fidelity structure of all app screens

### 🎨 UI Screens
High-fidelity mobile app interface designs

### 🔄 User Flow
Step-by-step navigation path of user journey

### 🚀 Prototype
Interactive app design generated from prompts

---

## 💡 Outcome
This project demonstrates how AI can quickly transform an idea into a complete mobile app design with structured UX flow and interface consistency.

---

## 🚀 Key Learning
- Converting ideas into app structure  
- Understanding user journey design  
- Importance of wireframes before UI  
- AI-assisted product design workflow
