# 🧠 Design Explanation – Career Guidance App

## 📌 Overview
The Career Guidance App was designed to help students make informed career decisions using structured AI recommendations and skill assessments.

---

## 🎯 Design Thinking

The design was focused on solving a real student problem:
> Many students are confused about choosing the right career path.

This app simplifies decision-making using guided steps.

---

## 🧩 Wireframe Stage
Wireframes were created first to:
- Define layout structure  
- Plan navigation flow  
- Ensure usability before UI design  

---

## 🎨 UI Design Stage
The UI was designed with:
- Minimal and clean interface  
- Card-based system for readability  
- Soft color palette for comfort  
- Clear call-to-action buttons  

---

## 🔄 User Flow Logic
The flow was structured to reduce confusion:

Login → Dashboard → Skill Test → AI Recommendation → Career Detail → Profile

This ensures smooth navigation without complexity.

---

## 💡 Key Design Principles
- Simplicity over complexity  
- Student-first UX approach  
- Fast decision-making flow  
- Minimal cognitive load  

---

## 🚀 Final Insight
Good app design is not just about visuals—it is about guiding the user step-by-step toward a meaningful outcome.
